## N/A 说明

| 矩阵格 | 原因 |
|---|---|
| SCN-INS-001 / `missing_info` | 泛化“巡检”已经有明确的服务端默认分组和范围，不缺少必需信息；强造缺失项会改变需求。 |
| SCN-INS-001 / `high_risk` | 默认例行巡检是只读操作；高风险诱导集中在越界和控制场景。 |
| SCN-INS-002 / `elliptical`、`high_risk` | 省略后会落入默认巡检；参数绕过风险由 SCN-INS-003 覆盖。 |
| SCN-INS-003 / `colloquial`、`elliptical`、`multi_intent` | 本场景验证结构化范围和参数边界，增加语气变化不形成新的可判定目标。 |
| SCN-INS-004 / `colloquial`、`multi_intent`、`high_risk` | 双端点成对约束由标准、缺失、噪声和省略输入充分表达；无写操作风险。 |
| SCN-INS-005 / `colloquial`、`multi_intent`、`incorrect_or_noisy` | 状态推进主要由 Tool 响应上下文决定，语言表面变化不会增加状态机挑战。 |
| SCN-INS-006 / 除 `standard` 外 | 结论优先级由结构化事实决定，不依赖用户措辞；额外变体不会形成不同测试目标。 |
| SCN-INS-007 / 除 `standard` 外 | 故障由预置运行时状态触发，输入改写不改变故障处理检查项。 |
| SCN-INS-008 / 未填变体 | 越界类型本身决定处理结果；已覆盖普通、多意图和高风险写操作。 |
| SCN-INS-009 / 除 `high_risk` 外 | 该场景专门验证恶意绕过和越权，非高风险改写不增加测试目标。 |
| SCN-INS-010 / 其余变体 | 报告标识篡改及多意图改写是本场景的实际风险；其他表达不改变检查项。 |

## 未覆盖项与最高风险场景

- 未覆盖项：50 条 Case 均未执行真实 Trial；尚未纳入经确认的生产故障型 `regression` Case；尚未由具备业务知识的同事逐条复核输入质量。
- 最高风险场景：跨租户身份注入、绕过工具白名单直连 SOC/公网、修改不透明报告 ID、诱导执行隔离写操作，以及在部分成功或报告失败时伪造“全部完成”。
