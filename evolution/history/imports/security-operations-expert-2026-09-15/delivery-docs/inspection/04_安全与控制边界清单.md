# 安全与控制边界清单

> 风险等级暂定为低：Agent 只执行读取证和报告生成，不具备隔离、删除、策略修改等业务写工具。Prompt 控制只作为补充；服务端身份、Schema、状态机、工具发布和网络部署仍需独立核验。

## 1. 数据边界

- 允许读取：由固定 tenant/workspace/principal 授权范围内的资产状态、漏洞、已知网络关系与路径检查结果；会话控制面的 collect 响应仅含状态、计数、覆盖率和 `next_action`。
- 禁止读取：其他租户或工作区数据；任意历史报告列表；计划任务列表；数据库、文件系统或 SOC 原始接口；工具未返回或能力目录未声明的数据。
- 租户或对象范围：身份由 Workbench 部署配置固定注入，请求不能覆盖。默认业务范围为 `scope.type=all`，含义是固定身份授权边界内的全部对象，不是跨租户全局。
- 输出最小化：会话不得获得原始证据；最终输出仅使用确定性 `user_response_markdown` 和报告地址。

## 2. 工具和网络边界

- 允许 Tool/MCP：能力目录查询、按计划创建运行、聚合取证、完成巡检，共 4 个巡检高层工具。
- 禁止 Tool/MCP：Bash、Shell、文件读写、任意网络工具、直接 SOC/资产/漏洞工具、历史查询、计划任务 CRUD、隔离/封禁/删除/策略/修复工具和其他 MCP。
- 允许网络范围：Agent 仅经配置好的 `/mcp/inspection-agent` 访问 MCP 管理平台；Workbench 经部署配置访问内部上游；报告地址仅允许相对路径或配置的 HTTP(S) 基址。
- 禁止网络范围：用户指定 URL、任意公网出站、绕过 MCP 直接访问 SOC，以及把报告或证据上传到外部地址。
- 强制性说明：工具白名单由子智能体声明和 Workspace guard 约束；最终是否构成不可绕过的运行时强制控制，仍需在目标部署做 Tool 轨迹验收。

## 3. 写操作与审批

| 操作 | 自动执行 | 需审批 | 禁止 | 回滚方式 |
|---|---|---|---|---|
| 创建只读巡检运行、推进取证、生成报告 | 是，在固定身份和 Schema 内 | 否 | 否 | `N/A`，不改变被巡检业务对象；失败时停止运行 |
| 写入巡检运行、事件、报告和趋势等内部记录 | 由 Workbench 运行时自动完成 | 否 | 对话侧不可直接写 | 依赖服务事务/状态机；本轮未验证运维回滚 |
| 隔离、封禁、删除、策略修改、自动修复 | 否 | `N/A`，本 Agent 无合法执行路径 | 是 | `N/A（策略永久禁止）` |
| 覆盖 tenant/workspace/principal 或跨租户访问 | 否 | `N/A` | 是 | `N/A（固定部署身份）` |
| 修改 `run_id`、报告 ID、服务端超时/并发/分页 | 否 | `N/A` | 是 | `N/A（服务端控制）` |

## 4. 执行环境与凭据

- Shell：禁止。
- Sandbox：会话子智能体只暴露 4 个巡检工具；不得使用 Bash、文件、网络或其他 MCP 兜底。目标部署的 Sandbox/Policy 实际配置尚待验收冻结。
- 凭据与最小权限：控制 API 当前是内网匿名接口，不使用应用层调用凭据；tenant/workspace/principal 来自固定部署配置并以 service 身份运行。必须通过内网隔离、固定配置和上游权限实现最小授权，请求不得自带身份。
- 凭据存放与轮换：仓库未给出独立巡检凭据轮换方案，正式交付前由部署/平台负责人补充；交付材料不得包含真实密钥。

## 5. 失败安全

- Tool 失败：向用户说明实际错误和可操作原因，立即停止；不得改走 Bash、文件、网络、直接 SOC 或其他 MCP。
- 信息不确定：不猜能力 ID、Schema、资产、IP、`run_id`、报告 ID 或状态；请求补充必要信息，或以服务端不完整/失败结论为准。
- 高风险动作失败：`N/A`，本 Agent 永久禁止高风险业务写动作；任何诱导均应阻断且不得产生业务状态变化。
- 部分成功：保留成功证据和覆盖缺口，结论必须为服务端确定的 incomplete/failed/abnormal/normal，不能把部分成功描述为全部成功。
- 重试与并发：只按 `next_action` 推进；同一 `run_id` 复用，服务端按运行串行化。Agent 不自行扩大并发、分页、切片或盲目重试。
- 转人工条件：能力或 Schema 无法确认；固定身份或控制 API 未配置；上游/MCP/报告生成失败；用户要求历史查询、任务管理、复杂根因或写操作；疑似跨租户和凭据问题。
- 留证：正式 Trial 必须保留最终回复、Tool 顺序及参数、身份与租户来源、`run_id`/`next_action`、服务端状态、覆盖率、报告摘要与哈希，以及写操作场景下“业务状态未变化”的证据。
