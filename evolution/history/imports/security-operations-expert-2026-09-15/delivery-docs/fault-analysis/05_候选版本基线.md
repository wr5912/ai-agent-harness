## 7. 配置与接口边界

- `FAULT_ANALYSIS_MCP_REQUIRE_TOOL_SNAPSHOT` 默认 `true`。
- `FAULT_ANALYSIS_EXPOSE_DEBUG_TOOLS` 只有显式设置为 `true` 才开放调试节点工具；正式评估必须保持关闭。
- 存储租户由部署变量 `FD_STORAGE_TENANT_ID` 提供，不能由用户输入覆盖。
- AI Console 查询要求 `ai:troubleshooting:monitor:list` 或平台全权限。
- Java 查询入口包括列表、目录、Run 详情和报告查询；用户侧监控为只读。Runtime Finalize 通过内部 Workbench API 写入故障记录、Run 索引和报告制品，因此不能把整个 Java 模块笼统描述为“完全只读”。
