# 研究假设

将旧 Harness 中仍有价值的提示、Skill 和任务素材迁入 DSH Candidate，并通过新容器、新 Session 观察实际装载，可以建立一条可重复的“修改 → 回流 → 观察”研究路径；旧 Runtime 配置、历史通过声明和生产化门禁不需要随之迁入。

## 预期观察

- 开发会话能识别本次目标并修改受 Git 管理的 Candidate。
- 变更范围能由回执说明，新被测会话能观察到变化，回退后变化消失。
- 历史失败和待复核输入保留为研究素材，但不阻止先用少量高价值输入验证新假设。

## 停止条件

- DSH 无法稳定装载所选 Candidate；
- 修改只能停留在容器运行状态，不能回流到源码；
- 新会话无法区分变更前后的行为；
- 继续扩大实现只是在提前建设生产权限、审批或发布平台，而没有增加当前研究证据。

## 当前范围

当前证据主要覆盖容器装载、Skill 修改小闭环和本地模拟 MCP。DSH Web 完整交互、新 Preset Web 选择、真实业务 MCP 和 Research Release 复现仍是未完成路径。
