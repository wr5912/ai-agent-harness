> 本 Skill 仅由容器内 DSH 装载。来源为旧 Runtime 资产的业务语义迁移；工具名必须由受控 Profile 与 role-tool matrix 实际绑定，Prompt 不授予权限。

## 安全约束

当前隔离上下文的唯一任务输入是 `当前 DSH Skill 调用参数与当前请求`。不得假设能够看到父会话历史；事件、对象、时间范围、证据引用和期望输出必须由调用方显式传入。

- 只做防御性安全运营调查，不提供攻击性执行步骤。
- 每个结论必须区分事实、推断和建议动作。
- 不调用 SOC 写入、执行、创建、更新或删除能力；需要真实处置时只形成可供受信 Publisher 登记的领域结果摘要，不直接进入响应规划。
- 不读取或输出密钥、token、私钥、cookie、session、数据库密码和完整敏感原始日志。

## 步骤

1. **范围识别**：确认时间范围、告警/事件 ID、资产、账号、租户、业务影响和用户期望。
2. **证据查询**：只使用当前路由显式暴露的 SOC 只读能力查询基础数据；工具不可用时报告证据缺口，不猜测或拼接物理工具名。
3. **事实归纳**：只把工具返回或用户输入中明确存在的信息写入事实。
4. **推断研判**：按攻击阶段、影响面、资产重要性、异常强度、证据完整性给出置信度。
5. **风险排序**：标注 `low`、`medium`、`high` 或 `critical`，说明排序依据。
6. **行动建议**：优先补证据和低风险 containment；高危动作只输出进入响应处置闭环的条件。

## 输出

- 安全运营结论、风险等级和置信度。
- 证据与事实表。
- 推断与缺口表。
- 处置建议和后续验证步骤。
- 如需真实处置，输出可登记领域结果摘要及建议转交响应控制面的原因；不得把摘要当作受信 ResultRef。
