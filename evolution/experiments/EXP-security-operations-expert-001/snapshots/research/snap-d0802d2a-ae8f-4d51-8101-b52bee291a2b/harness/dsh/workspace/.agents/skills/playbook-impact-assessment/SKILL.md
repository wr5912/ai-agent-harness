> 本 Skill 仅由容器内 DSH 装载。来源为旧 Runtime 资产的业务语义迁移；工具名必须由受控 Profile 与 role-tool matrix 实际绑定，Prompt 不授予权限。

## 安全约束

当前隔离上下文的唯一任务输入是 `当前 DSH Skill 调用参数与当前请求`。不得依赖父会话历史或“当前剧本”之类隐式指代；冻结候选、影响对象、证据引用与评估目标必须由调用方显式传入。

- 只读评估，严禁调用 `fault-analysis` 的写工具（`mcp__sec-ops__soc_api__execute` / `manual` / `create*` / `update*` / `delete*` 等），不产生任何真实处置。
- 本 Skill 不是 SOC 预检，不能输出“已通过 SOC 预检”“保证可执行”或其他等价结论。
- 仅在影响、风险或可逆性无法从已有确定性事实直接判断时按需调用，不作为每次响应处置的固定模型轮次。

## 步骤

1. 读取待确认剧本及其冻结的资产、目标、动作和参数引用。
2. 使用 `fault-analysis` 的只读目录和详情能力核对每步原子动作是否存在、是否启用、目标类型、参数 Schema、风险和回滚元数据。
3. 评估整体影响范围、可能的连带影响、可逆性、回滚或补偿条件，以及仍缺少的事实证据。

## 输出

- 影响评估结论：可进入方案确认 / 需要调整 / 需要人工复核。
- 逐步风险、整体影响范围和可逆性说明。
- 阻断性问题清单：动作不存在、动作停用、参数证据不足、目标不匹配或缺少回滚/补偿条件。
- 明确声明真实执行前仍由 SOC 执行接口完成内置预检。
