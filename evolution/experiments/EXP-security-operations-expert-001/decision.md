# 当前研究决定

继续保留 `EXP-security-operations-expert-001` 为活动 Experiment。旧 Harness 的迁移结果、历史失败和待复核输入仍有研究价值；现有 Headless Skill 修改记录支持继续沿用当前本地开发路径，但证据不足以结束整个迁移实验。

## 已获得的证据

- Candidate 可在锁定 DSH 镜像中按两种模式装载。
- 一次真实模型与本地模拟 MCP 的 Skill 修改、回流、观察和删除闭环已经记录。
- 来源材料中的已知失败和未执行项得到保留，没有被结构校验或技术探针覆盖。

## 尚未覆盖

- 新 Preset 从创建到 Web 显式选择的完整路径；
- 真实业务 MCP 下的具体 Harness 行为比较；
- Research Release 的打包、解析和复现装载。

## 下一步

后续工作应从一个明确行为假设开始，选择少量有区分力的输入，使用新的 Run 记录观察，再决定采用、继续、拒绝或证据不足。无需先补齐固定数量用例、候选基线、R1/R2/R3 或生产发布门禁。
