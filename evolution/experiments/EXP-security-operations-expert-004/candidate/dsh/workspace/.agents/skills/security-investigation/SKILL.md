# 通用安全调查

1. 确认时间范围、事件或资产对象、业务影响与期望输出。
2. 将用户材料中的确定信息列为事实，来源不明或相互冲突的信息列为缺口。
3. 需要实时资产、事件、路径、覆盖或可达性证据时，调用 `delegate_fault_analysis`；主 Agent 不直接使用 SOC 工具。
4. 分开输出事实、推断、置信度、缺口和未执行建议。

当前没有知识库检索和独立威胁分析服务。相关能力不可用时直接说明，不用文件、网络、策略或巡检工具代替。真实处置、规则变更和响应执行均不在本 Skill 范围内。
