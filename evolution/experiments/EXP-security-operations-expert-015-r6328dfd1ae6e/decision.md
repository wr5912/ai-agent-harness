# Decision：continue

2026-10-10。保留三工具合同的 EXP-015 Candidate 作为后续巡检研究来源：新实例的目录查询、一次常规巡检和同一 Session 两轮续查均有真实工具回执与 Run。周期任务创建 `U-INS-005` 明确失败：服务源码已有 REST 创建入口，当前 MCP 没有；当时该 Case 也未给出已批准周期任务合同要求的固定目标。指定资产 `U-INS-006` 只能证明按范围发起，MCP 查询结果报错，同一 `runId` 的 REST 详情也返回 HTTP 500。2026-10-11 的[浏览器补充试跑](evaluation/observations.md)验证了概览→MCP 配置→常规巡检与同 Session 续查的一次完整页面路径；另有两个新 HOME 的正式浏览器 Run 完成简单 UI 冒烟，新增失败 Run 在连接工作区时超时，完整路径仍缺新实例复测和跨实例身份对应。历史业务评测判定由同路由模型辅助产生，浏览器通道现只做 UI 冒烟，不能据此采纳为完整的运行平台试点。
