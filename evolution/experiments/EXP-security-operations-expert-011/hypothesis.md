# 研究假设

以当前启用的 EXP-008 Candidate 为起点，只扩展其 DSH Web 插件和两条子智能体路由说明，就能在保留 DSH 原生输入框、会话侧栏与系统消息面板的前提下，呈现参照页“智能对话”的主要布局与图标，并让推荐任务和数字员工卡片在新 Session 中生效。参照页使用的图片保存于本 Experiment 的 Candidate，运行时不请求参照站点。

预期在桌面与窄屏浏览器中看到本地品牌图标、AI-SOC 头像、六张推荐卡片和两张数字员工卡片；搜索可过滤当前页卡片；点击卡片只向输入框插入文字。会话收藏对应 DSH 原生置顶功能。输入 `@威胁研判子智能体` 或 `@故障分析子智能体` 后，Agent 应按现有路由和工具约束处理，不显示受 Guard 限制的响应规划子智能体。

以 `git:97236e16ebca8e49623959ec9afdfe77002bbdb9` 为 Baseline，先检查页面、装载和交互，再用现有业务 Case 与新 Session 核对真实路由及工具轨迹。若页面装载、草稿插入或路由失败，则不切换当前 Experiment；外部 MCP 或模型不可达时，把界面与业务验证结论分开记录，不以静态检查替代真实行为。此实验不涉及运行平台或 Research Release。
