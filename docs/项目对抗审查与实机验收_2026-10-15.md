# 当前平台与智能体对抗审查及实机验收

本轮将用户要求的归档特性融合、Experiment 命名根因整改，与当前项目的对抗性审查和真实环境验收一起完成。开始时主线为 `189501d`；归档来源随后固定为 `4778924`。审查对象是当前平台、工具链和实际业务智能体，历史 Run 只用于核对相关主张，不逐条重审全部历史。

## 从目标推导检查条件

平台的价值是让用户可靠地选择资产、理解版本、配置外部能力并观察真实执行。智能体的价值是用授权的数据和工具完成运营任务，如实交付结论、失败与缺口。因此，本轮以实际调用链核对以下条件：

- 用户确认的版本、目标和对象，必须与最终副作用一致；同名配置和后来发布不能悄悄替换已确认对象。
- 同一运行的身份、证据、模型、外部目标和终态必须连续；取消和重启不能留下无法解释的业务状态或重新执行。
- 业务完成、输出校验、保存成功、工具发现和页面成功是不同事实；模型回答、文件存在、HTTP 200 和测试数量不能互相代替。
- 凭据只进入所需运行边界；提案、会话、日志、证据和 Git 不能成为凭据副本。
- 融合必须同时保留来源能力；不能用较新的编号、空特性列表或整包覆盖来推断继承。

## 审查范围和整改计划

审查沿六个页面追到共享 RPC、助手确认、版本与特性、用例及 Run 下载、实例命令、MCP 连接与组合、事件刷新和站点基址。业务侧追到新融合 Candidate 的 Guard、工具与资源、威胁认领和自动任务、策略应急确认、巡检续查、故障取证、材料整理及语音摘要。原生 Runtime 只核对锁定来源、公共接口和实际装载，不把其外部源码当作本项目整改范围。

| 规则生效后新增的无后缀 EXP013、EXP020 被宽松校验当作旧名称放行。 | 保留历史身份及 Run，冻结有限历史兼容集合；陌生无后缀 ID 即使提交 Git 仍必须拒绝，所有创建入口继续生成随机后缀。 |

| 平台普通重启重建容器时，可能丢失 CLI 注入的 MCP Token 和后端环境变量。 | 在统一 CLI 的停机前恢复同来源声明且未显式提供的运行值；显式空值优先，不把值写入状态或日志，查询失败先拒绝。 |

| 认领后取消直接终止 Python，可能跳过失败回写。 | 认领后立即落身份检查点；等待旧进程退出后有界清理同一运行；重复清理不重写，目标漂移时保留未知状态。 |

| 部分内部 MCP 回环地址遗漏 `/assistant/` 站点前缀。 | 统一通过原生 `webServer.publicPath` 派生，验证根路径、正式前缀和多级前缀。 |

| 后台实例通知清除用户正在确认的预览。 | 通知只刷新观察，保留预览；执行前在实例锁内验证预览来源，来源变化拒绝操作。 |

| Mock 报告下载均为同一固定正文，无法核对本次运行。 | 只保留严格格式的运行、事件及路由元数据，固定安全模板不接收上游 HTML；回执明确 `originalContentStored:false`，独立真实 MCP 保存下载及新 Agent 全链复验。 |

| Agent 当前研究引用仍指向 EXP008，平台默认派生会从旧能力出发。 | 将唯一 `manifest.active_experiment` 更新为本轮 EXP021；它是当前研究引用，Decision 仍为 continue，部署状态继续以实例来源为准。 |

实施顺序是先固定来源和命名边界，再修复版本、目标、凭据与生命周期问题，随后重建受影响制品，运行反例及既有回归，最后在独立实例和实际平台验收。发现新的实机问题时保留首次失败记录，修复共同根因后重新执行受影响路径；不降低验收条件来获取通过结果。

命名根因已核对 Git 历史：随机后缀规则在 `d89ad8bc611f`（2026-10-09）引入，本地裸 EXP020 在后续 `524c5646f152`（2026-10-15）首次入库；裸 EXP013 在 `8e28fd1c39a3` 同样晚于规则。正常 CLI、平台创建和融合入口均生成12位随机十六进制后缀，校验却把任何无后缀身份当成历史格式放行，无法阻止绕过标准创建入口的新增目录。Git 不能还原当时实际执行的命令，不能断言由某个具体脚本或操作者生成。整改将历史兼容固定为有限集合，陌生裸ID即使已提交也拒绝；按现行规则保留既有013/020名称、引用和封存Run，不追溯改名。归档实际 EXP020 本身已有随机后缀，属于另一研究；本轮融合使用工具生成的合规 EXP021。

## 实机验收范围

保留原有 3081 业务实例及共享 53001 Mock 状态。新融合使用标准 Runtime 镜像、独立 HOME 和只读 Candidate，在新实例、新 Session 中验证。独立 53002 Mock 只提供基本正常数据；53003 协议夹具只把其实际接口转成 MCP 工具、资源和模板，不在智能体内部伪造结果。所有模拟边界、模型及未测范围进入对应 Run。

平台需验证登录、导航、助手确认与续接、版本和评测读写、报告及完整产物下载、实例来源及重启、MCP 保存发现与组合执行，以及刷新、失败和窄屏路径。业务需分别核对材料零工具、巡检续查不重发、只读故障边界、策略与应急原生交互、手动与受信自动研判、固定结果摘要和取消。

项目与工具链检查更新到 [PA-03/04/05/06/08/12](ai-agent-harness项目验收矩阵.md)；融合来源、逐项实际观察和 Decision 集中在 [新 Experiment](https://github.com/wr5912/harness-engineering-platform-data/blob/9afc8fd0047367deb9df5b51595f101835359044/evolution/experiments/EXP-security-operations-expert-021-rdd331f9f2e30/hypothesis.md)。归档原观察不是本轮通过证据，Mock 验收不是实际 SOC 或生产服务验收，也不形成 Research Release。

## 实际结果与证据

平台最终构建、类型检查及 184 项测试通过。已在正式 `/hap/` 地址验证六页、刷新、390px 窄屏、原生管理对话、真实模型助手提案与确认、只读组合、报告及完整 ZIP 下载。助手确认绑定不可变版本，重复确认复用回执；含演示凭据的 URL 在真实工具调用中被拒绝。跨版本发布竞态由核心定向测试覆盖，没有在用户的在线组合上制造发布竞态。逐项机器证据见 [平台验收汇总](https://github.com/wr5912/harness-engineering-platform-data/blob/9afc8fd0047367deb9df5b51595f101835359044/evolution/experiments/EXP-security-operations-expert-021-rdd331f9f2e30/evaluation/evidence/platform-acceptance/acceptance-final.json)。

新实例通过平台界面重启，未额外提供环境变量，原有 18 项环境值、HOME、配置及只读来源保留。随后再次重启装载最终语音修复，新 Session 创建和真实模型调用通过。原 3081 实例及共享 53001 Mock 保留。主机原 65536 个文件监听额度被其他桌面进程耗尽，已临时调整为 131072，未写持久化系统配置；新实例最终启动没有插件激活警告。

业务实际观测包括材料零工具、巡检与同次续查、只读故障证据不足、策略端点原生单选、草案确认与取消、威胁快速及完整研判、普通追问、受信 Schedule 的空队列心跳和任务删除。语音真实模型摘要分别约 870ms 和 923ms，原生连接收到摘要；首轮固定结果也保留取消和未执行语义。这些只是两个试次的观测，不能据此推断总体性能收益。

技术 [Run](https://github.com/wr5912/harness-engineering-platform-data/blob/9afc8fd0047367deb9df5b51595f101835359044/evolution/experiments/EXP-security-operations-expert-021-rdd331f9f2e30/runs/run-8350ed24-963c-4c44-a1f9-d5ef7c9efe7e/report.md)保留原始回答、工具轨迹和失败。除缺少 ID 外，本轮使用了基础 Mock 资产和事件替换输入；原 Case 未原样执行，Run 未将这些变体标为原 Case 通过，也不用于跨版本收益比较。首次业务试跑之后发生的语音修复与重启，按独立证据记录，不倒改起始来源摘要。

仍有明确边界：真实 TTS 地址连接超时，页面提示播报失败，实际音频及 ASR 效果未完成验收；完整研判取得可提取结论，但输出路径校验为 `failed`，不能称输出校验或真实业务正确性通过；报告是绑定运行身份的基本模拟模板，上游原文没有存储。以上均不通过修改外部仓库、伪造业务数据或放宽判定来消除。

验收实例3084及其必要基础 Mock 保留，方便核对会话；它们使用测试主机回环服务，报告地址不作为远程客户端部署合同。已删除本轮测试自动任务，并停止不再使用的53003、53006协议夹具；当前运行边界及停止方式见[运行状态记录](https://github.com/wr5912/harness-engineering-platform-data/blob/9afc8fd0047367deb9df5b51595f101835359044/evolution/experiments/EXP-security-operations-expert-021-rdd331f9f2e30/evaluation/evidence/runtime-final.json)。原3081、共享53001及平台3090继续运行。
