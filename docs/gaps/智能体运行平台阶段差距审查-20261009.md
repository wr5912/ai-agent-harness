# 智能体运行平台阶段差距审查（更新至 2026-10-12）

## 范围与结论

仓库当前仍处于 Research Mode。长期方向是“研究验证 → 自用工具 → 能力逐步完善 → AI 原生的 Harness 工程平台”；阶段转换时复用已验证的资产、来源和 Run，不预设新仓库或生产平台。[项目规则](../../AGENTS.md)、[平台方案](../DSH智能体运行管理平台设计方案.md)。本文件记录走向其中**运行管理能力**的证据与差距，不把未来平台功能列为当前研究仓库的缺陷；项目与工具链的 `PA-xx` 状态以[验收矩阵](../ai-agent-harness项目验收矩阵.md)为准。

**当前判断：概览→MCP 配置→真实巡检与同 Session 续查已在 EXP-015、EXP-017 的不同实例各走通一次；EXP-017 新实例返回 `PARTIAL`，因此这次只确认页面与工具链路。两个新 HOME 的正式浏览器 Run 另通过简单 UI 冒烟。EXP-017 的周期任务已有两次真实到期并完成巡检。跨实例身份与状态的页面归属、部分历史能力继承和上游业务结果仍有差距。** `server/discover` 返回 HTTP 200、JSON-RPC `-32601 Method not found` 不阻塞已观察到的 DSH 使用：保留服务签发的 Session，依次执行 `initialize → notifications/initialized → tools/list` 后能发现并调用巡检三工具。单独的 HTTP 状态码不能证明工具可用。[协议观察](../../evolution/experiments/EXP-security-operations-expert-014-r8b1bd54e8be7/evaluation/observations.md)。周期巡检使用 DSH 自动化任务插件；[EXP-017](../../evolution/experiments/EXP-security-operations-expert-017-r94f3b07e080f/evaluation/observations.md)已取得任务创建、两次到期投递及对应三工具调用的原始回执。

## 当前 Research Mode 先补的闭环

选一项有原始失败证据的真实研究问题，连续完成“选定 Agent、Experiment 和 Run → 核对 Git 来源、dirty 状态与实际装载 → 查看 Case 快照和原始工具回执 → 修改对应 Candidate → 用新实例、新 Session 重跑受影响 Case → 比较回归与限制 → 写入 Decision”。现有 CLI 已覆盖若干步骤；尚需用同一任务重复验证这条路径是否减少来源错误或查证劳动，再决定沉淀为自用工具。[平台方案的首个工具切片](../DSH智能体运行管理平台设计方案.md#首个工具切片与价值验证)、[验收矩阵](../ai-agent-harness项目验收矩阵.md)。

[EXP-017 故障分析复测](../../evolution/experiments/EXP-security-operations-expert-017-r94f3b07e080f/evaluation/observations.md)已沿上述路径保存失败来源、Candidate 修正、隔离新实例 Run、原始回执与 `continue` Decision；它证明这条研究路径可执行，尚无减少查证劳动或跨实例页面对账的证据。

[EXP-015-r632](../../evolution/experiments/EXP-security-operations-expert-015-r6328dfd1ae6e/decision.md)的 Candidate、Run 和相关研究记录目前仍在本地工作树，尚未形成可从远端恢复的提交。封存前须核对来源、证据引用、敏感内容与校验结果；这属于研究结果的可复现与交付差距，不代表需要新建平台存储。

## 运行平台阶段的 P0：选定试点后逐项验收

1. **确定首条用户路径的阶段合同。** 研究试点选开发者使用 `security-operations-expert` 的单个实例：核对来源与状态、查看 MCP 配置、发起常规巡检、同 Session 续查，并对齐页面回答与原始回执。完整路径已在 EXP-015 和 EXP-017 的不同实例各走通一次；EXP-017 首轮超过现有评测器的 120 秒等待上限后才完成，所以上限不能当作服务时延承诺。何时进入运行平台阶段及其用户等待、错误展示和工程边界仍需确定。[平台方案](../DSH智能体运行管理平台设计方案.md)。
2. **建立 Agent、实例、来源与实际状态的对应关系。** 实例内概览统计 DSH 会话和事件；`research-tool` 已对 EXP-017 当前实例查到运行状态、镜像和挂载匹配，[同实例页面](../../evolution/experiments/EXP-security-operations-expert-017-r94f3b07e080f/evaluation/evidence/browser-path-20261012/overview-mcp.json)显示非零工具与 Skill 计数。但还没有跨实例页面把 Agent ID、实例 ID、期望来源、实际镜像与 Harness 装载、容器状态、DSH 活动、观察时间及错误放在同一条可核对记录中。停止、重启或失联时应显示实际结果或“未知”，不能把旧概览的“空闲”解释为容器健康。[实例来源与状态](../../evolution/experiments/EXP-security-operations-expert-017-r94f3b07e080f/evaluation/evidence/browser-path-20261012/source-state.json)、[实例入口](../../runtime/adapters/dsh-container/research-tool.mts)。

完整页面路径的新实例复核已由[EXP-017 浏览器观察](../../evolution/experiments/EXP-security-operations-expert-017-r94f3b07e080f/evaluation/observations.md)完成，不再列为待办 P0。简化浏览器执行器仍只做 UI 冒烟，业务结论以 API Run 与原始工具回执为准。

周期提醒与巡检闭环已在当前绑定的 232 服务完成两次真实到期验证，见[EXP-017 原始回执](../../evolution/experiments/EXP-security-operations-expert-017-r94f3b07e080f/runs/run-3c86eb9a-b49b-435e-aad3-0610c8fab123/evidence/U-INS-005/periodic-due.json)，不再列为未完成的 P0。历史 `A-001` 指定资产结果查询返回服务端错误，见[巡检观察](../../evolution/experiments/EXP-security-operations-expert-015-r6328dfd1ae6e/evaluation/observations.md)；该上游问题作为外部观察保留，用户已明确忽略报告修复上线到 232，本仓库不以其审批、源码修改或发布作为差距。故障分析的目标资产已有真实只读查询，但仍缺巡检侧同对象证据；策略服务可达性、应急目标精确匹配仍决定相应业务 Case 能否验证，见[四服务观察](../../evolution/experiments/EXP-security-operations-expert-015-r904bdcd81005/evaluation/observations.md)；真实 `ai_soc_*` 规范出现后再验证调用。

## 按实际使用触发的后续能力

- **来源修改与回退。** 研究 CLI 有来源、差异和实例操作；平台写入出现时，需实测“改 Candidate → 新装载 → 行为核对 → 切回旧来源”，并区分期望配置与实际加载。现有 [PA-07](../ai-agent-harness项目验收矩阵.md#pa-07-宿主修改装载观察与回退闭环)只部分覆盖。
- **长期实例、Trace 与恢复。** 仅当试点提供持续服务或容器写操作时，连接启动、停止、重建、活跃会话影响、操作回执与重启后的状态对账；保存 Session 与原始证据在运行存储，不把 HOME 复制成 Harness 资产。[平台方案](../DSH智能体运行管理平台设计方案.md)。
- **能力 Hub、反馈评估、版本与多用户。** 跨 Agent 复用、非 CLI 使用者、独立研究版本或第二位用户出现后再逐项建设。Research Release 的[复现路径](../ai-agent-harness项目验收矩阵.md#pa-11-research-release-打包解析与复现装载)尚未实现，不是首个单实例试点门槛；多人共享时需另验 Session 与任务归属。[平台方案](../DSH智能体运行管理平台设计方案.md)。
