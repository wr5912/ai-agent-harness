## 长期方向与现阶段边界

项目采用**研究验证（R0）→ 自用工具（R1）→ 数据体系（R2）→ 工具闭环（R3）→ 平台构建（R4）→ 持续演进（R5）**的能力演进路线。长期目标是将真实验证有效的 Harness 资产管理、受控改进、评测、多算力变体和 DSH 实例管理逐步内生为 AI 原生智能体运行管理平台的核心能力，而不是为未来平台永久维护一个外部研究事实源。

**目前仍处于 Research Mode**。现有 `dsh-dev` / `dsh-eval` 等自用工具已体现部分后续阶段能力，但不表示数据库、GUI/LUI、MCP 组合 Gateway、平台版本发布或业务路由已经实现。未来能力仅在有明确需求、真实证据并经项目范围调整后按最小切片建设；详细原则见 [`docs/项目能力演进原则.md`](./docs/项目能力演进原则.md)。
