# 报告与架构图呈现约定

## 两项产物

默认在用户指定目录，或 `/tmp/project_vision_gap_assessment/` 下的独立本次目录，交付 `任务拆分说明.md` 与 `AI-Agent-Harness-未来平台架构与当前进展映射图-4K.svg`。不覆盖旧评估；历史报告仅供可比分析。SVG 显式设置 `width="3840" height="2160" viewBox="0 0 3840 2160"`，这是 4K 画布尺寸，不声称 SVG 是位图。使用可用的矢量绘制能力，中文优先，检查字体、裁切、对比度和线条落点。

先完成报告中的任务树、判断、权重与数值，再据同一任务编号和汇总绘图；不维护第二份可手改的 YAML、JSONL 或图片状态表。绘图工具需要临时数据时，从报告生成，并保持临时文件可丢弃。图中可汇总任务组，但每组须以编号指向报告的完整任务清单；图中的任务、百分比和关系不能超出报告依据。

## `任务拆分说明.md`

正文直接说明目标、实现与方法版本、选定情境、纳入与排除范围、检查覆盖和结论限制。列出“分区—功能域—模块—任务”的唯一清单，每项包含编号、完成标准、权重与目标依据；用相同编号记录当前实现、`c/m/u`、证据位置和版本、未达或未知的原因。随后列模块、功能域和整体的 `P/G/U`，解释当前阶段影响与远期启动条件。有可比历史报告时按实现、证据、目标和方法四类解释变化；首次评估注明无历史趋势。最后说明图面编号、关系和颜色语义、无法核实事项及产物检查。长解释用段落，表格仅用于任务和数值索引。

不得把评估报告写成持续编辑的项目状态源，不抄录凭据、Token 或私有地址。结论引用原始资料和具体版本；静态检查、真实装载、业务行为的证据边界要可见。报告应能独立复算图中数字。

## 平台画面

采用横向全景：顶部为使用入口与场景；中部展示未来平台的确定性服务、管理界面与智能辅助，并在侧面呈现观察、候选修改、评测和人工 Research Decision 的研究演进；中下部为控制与适配；下部为受管 DSH 实例、Session 和任务；底部是业务资产、当前 Case、历史 Run、Decision 和运行态存储。DSH 原生能力画为外部复用基础，不直接计入本项目进度。实例数量仅作拓扑示意时明确标注，不暗示当前已运行。

未来业务版本切换另成分支：不可变装载清单、操作者决定、新 Session 直接切换、旧 Session 保持绑定、后续新 Session 回退。Research Decision 不能画成业务发布许可；不画灰度或流量权重路径。实线只表示已确认存在的调用或数据关系，虚线表示目标关系；箭头标明控制、数据或研究反馈。两端各自存在不等于连接已成立。

## 状态与标题

蓝色 `#2563EB` 表示已确认满足目标；橙色 `#C2410C` 表示已有实现但目标尚未全满足；红色 `#B91C1C` 标识已确认差距；灰色 `#64748B` 是结构、外部基础或待核实底色，待核实另加 `?` 和文字。颜色与文字同时表达状态；灰色目标骨架不等于“未开展”，红色不等于当期阻塞。进度条只按 `P/G/U` 的已计算比例绘制，未知段加纹理或问号。

标题写“AI Agent Harness：未来智能体运行平台架构与当前进展映射图”，紧邻标题显示整体 `P/G/U` 或“分母待确认”，并标注目标与代码版本。图例写明：`100%` 对应本次明确的未来目标范围，不是工时或生产就绪度。局部模块比例同样显示已确认与未知部分，不用“部分实现=50%”之类视觉假分数。

完成前核对报告和 SVG 的编号、名称、数值、总和、配色、状态文字及已确认连线；必要时实际渲染检查中文和遮挡。缺少绘图能力或产物失败时如实交付已完成部分并说明缺项，不能以提示词、占位图或低清图片替代 SVG。
